快速开始

PointerEditor 有 Windows 安装版、Windows 免安装版和网页版三种使用方式。先选一种打开，再用几分钟做出第一个作品。

选择使用方式

方式适合特点
Windows 安装版长期在 Windows 上创作注册 .sb3 / .sb2 / .sb 文件关联，双击打开，支持保存到原文件
Windows 免安装版U 盘、临时使用、多个版本共存解压即用，项目数据保存在程序目录
网页版快速体验、换电脑使用无需安装；不支持 Windows 文件关联和原生保存
下载最新版本 立即体验网页版 浏览扩展商店

Windows 安装版

  1. 从 国内官方节点 或 GitHub Releases 获取 PointerEditor-0.3.0-Beta2-setup.exe。
  2. 运行安装器，选择“仅为我安装”或“为所有用户安装”，可以修改安装目录。
  3. 首次运行如果出现“未知发布者”，选择“仍要运行”；当前版本没有代码签名。
  4. 安装器会创建桌面和开始菜单快捷方式，并注册 .sb3、.sb2、.sb 文件关联。

安装版的项目数据和导出文件保存在程序目录下的 PointerEditorData 与 PointerEditorExports。

Windows 免安装版

  1. 下载 PointerEditor-0.3.0-Beta2-win64.zip（国内官方节点；海外可从 GitHub 下载）并解压到任意目录，建议放在非系统盘。
  2. 双击 PointerEditor.exe 运行。
  3. 免安装版不会注册系统文件关联；需要双击打开 .sb3 时请使用安装版，或用“文件 → 从电脑中打开”。

网页版

直接打开 PointerEditor 在线 即可。网页版使用浏览器本地存储，保存作品时请通过编辑器下载 .sb3 文件。

第一个作品

  1. 打开编辑器，默认会创建一个新作品。
  2. 在左下角角色区添加角色，或使用顶部“造型/声音”编辑素材。
  3. 从左侧积木分类拖出积木，拼到中间工作区。
  4. 点击舞台上方绿旗运行，红色圆点停止。
  5. 按 Ctrl+S 保存到原文件，或使用“文件 → 另存为”（Ctrl+Shift+S）选择新位置。

打开和保存作品

  • 双击 .sb3 文件，或在编辑器里按 Ctrl+O 从电脑中打开。
  • 使用安装版打开 .sb3 后，按 Ctrl+S 会直接保存回原文件。
  • .sb2 / .sb 作品可以打开，但另存时会保存为 .sb3。
  • 网页版和免安装版不会注册系统关联；请使用菜单打开，网页版保存时下载文件。

系统要求

  • Windows 10 / 11 x64；网页版建议使用最新版 Chrome 或 Edge。
  • 首次打开项目或使用视频侦测时需要摄像头权限；音频功能需要麦克风权限。
  • PEAgent 需要可访问所填模型接口的网络环境。
