常见问题与更新

这里收集最常见的问题。如果仍然无法解决，欢迎到 GitHub Issues 反馈。

账号与登录

PointerE 账号和创客次元账号通用吗？

不通用。PointerE 用于编辑器在线协作，创客次元用于作品社区和发布，两者独立管理。

注册后没有收到验证邮件？

检查垃圾邮件；等待几分钟后重试；确认邮箱拼写正确。如果仍然收不到，请联系维护者或稍后再试。

忘记密码怎么办？

目前请通过维护者重置；后续会补充自助找回流程。

作品保存

我的作品保存在哪里？

桌面版在程序目录的 PointerEditorData 和 PointerEditorExports；网页版在浏览器本地存储和下载目录。重要作品请导出 .sb3 备份。

为什么双击 .sb3 没有用？

只有安装版会注册文件关联。免安装版和网页版请通过“文件 → 从电脑中打开”打开，或在系统“打开方式”中手动选择 PointerEditor。

.sb2 / .sb 可以保存回原格式吗？

可以打开，但保存时会另存为 .sb3；这是当前 Scratch 运行时的导出格式。

PEAgent

API Key 会上传到 PointerE 服务器吗？

不会。桌面版把 Key 加密保存在本机，请求直接发送到你填写的模型接口。

为什么提示 401 或余额不足？

401 通常是 Key 无效或服务商/接口地址不匹配；余额不足需要在模型服务商处充值。AI API 费用由服务商按 token 收取，与 PointerEditor 无关。

Agent 会执行任意代码吗？

不会。它只能创建变量/广播、插入经过校验的 Scratch 积木、添加 SVG 造型，不会执行任意 JavaScript。

协作

为什么不能修改某个角色？

角色可能已被其他成员认领，或房主锁定了全部代码。可以发送编辑申请或让房主解锁。

协作断开怎么办？

检查网络和 WSS 地址，重新连接房间。房主可以重新同步整个项目；重要修改建议先导出 .sb3。

扩展

安装扩展后没看到分类？

安装成功后扩展会直接出现在积木区左侧。若没有出现，刷新/重新打开编辑器，或检查扩展是否加载失败。

社区扩展加载失败？

检查网络、地址是否为有效的 .js、是否被浏览器拦截，以及扩展作者的服务是否可用。自定义扩展只从可信来源加载。

扩展能卸载吗？

扩展会记录在作品文件中；重新打开作品时会自动恢复。需要重置时刷新或新建项目，再重新选择需要的扩展。

版本与跨平台

当前版本是什么？

当前为 0.3.0 Beta2（测试版，可能存在不稳定）。发布记录见 GitHub Releases。

会有 Linux / macOS 版本吗？

计划先做 Linux 测试版（AppImage / deb），macOS 需要签名与公证，会在有明确需求后推进。

源码和许可证？

源码在 GitHub，整体以 GPL-3.0 分发。PointerEditor 与 MIT、Scratch 团队无隶属关系。

0.3.0 Beta2 更新摘要

  • 新增工作区背景自定义：预设、纯色与本地图片，可调背景模糊、面板模糊与面板透明度。
  • 工作区背景设置已移入「高级设置 → 外观」，不再占用编辑器右下角。
  • 深色/浅色主题与设置里的「切换到暗色/亮色主题」联动：默认工作区背景、分类栏、面板和设置弹窗同步切换，深色背景仍会自动切深色。
  • 修复主题切换在系统本身为深色时不保存、重启后又回到浅色的问题。
  • 新增云空间：编辑器内上传、下载、重命名和删除云端 .sb3 作品与角色，角色卡片右键可上传。
  • 新增 PointerE 账号中心：积分、积分商城与收货地址。
  • 修复深色模式下 FPS 绿色状态、舞台按钮图标与全屏背景颜色。
  • 本版本为 Beta 测试版，可能存在稳定性问题，请先备份作品再使用。
